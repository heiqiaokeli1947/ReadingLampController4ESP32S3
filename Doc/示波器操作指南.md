本指南记录 ReadingLampController4ESP32S3 项目中使用 Siglent SDS2204X HD 示波器测量 PWM 信号的操作方法，包括 Web 界面操作和 SCPI 远程控制两种方式。

## 2. 探头连接

本项目 PWM 信号引脚与示波器通道的对应关系：

| 示波器通道 | ESP32-S3 GPIO | 信号 | 配置频率 | minDuty | maxDuty |
|-----------|---------------|------|---------|---------|---------|
| CH1 | GPIO16 | 白灯 PWM (whitePwm) | 25 kHz | 6% | 100% |
| CH2 | GPIO17 | 黄灯 PWM (yellowPwm) | 25 kHz | 5% | 100% |
| CH3 | GPIO18 | 水泵 PWM (pumpPwm) | 25 kHz | 15% | 100% |
| CH4 | GPIO8 | 风扇 PWM (fanPwm) | 25 kHz | 15% | 100% |

> 注意：CH3/CH4 在风扇/水泵关闭时可能检测到来自 LED PWM 走线的电磁串扰信号。判断是否为真实信号的方法：关灯后若信号消失，则为串扰而非真实 PWM 输出。

## 4. SCPI 远程控制（推荐）

### 4.1 连接方式

示波器提供两个 SCPI 端口：

| 端口 | 协议 | 特点 |
|------|------|------|
| 5025 | Raw TCP | 命令直接响应，但超时后连接易卡死 |
| **5024** | Telnet 风格 | 带 `>>` 提示符，超时后恢复能力强，**推荐使用** |
| 111 + 动态端口 | VXI-11 | 手册（p.8）支持 VXI-11，VISA 资源串 `TCPIP0::192.168.30.105::inst0::INSTR`。**2026-11-10 实测**：仪器应用卡死期间用 pyvisa-py 连接返回 `VI_ERROR_RSRC_NFOUND`——VXI-11 随仪器应用一起卡死，**不能**作为卡死恢复通道，仅是健康状态下的另一种客户端 API |

#### 客户端 API 对比（裸 socket vs PyVISA）

| 客户端 API | 资源串 / 端口 | 优点 | 缺点 |
|---|---|---|---|
| 裸 TCP socket（`TcpClient` / Python `socket`） | 5024 端口 | 完全掌控提示符解析；超时恢复能力最好；二进制传输（`PRIN?` 截图）最简单 | 需自行处理 `>>` 提示符、命令回显、偶发的开头 NUL 字节、半包读取 |
| PyVISA SOCKET 资源 | `TCPIP0::192.168.30.105::5024::SOCKET` | 熟悉的 VISA API；自带超时与缓冲 | `>>` 提示符字节会混入读数据（见下）；示波器卡死时与裸 socket 一样失败 |
| PyVISA VXI-11 | `TCPIP0::192.168.30.105::inst0::INSTR` | 最高层的标准仪器 API，无需处理提示符 | 随仪器应用一起卡死（2026-11-10 实测），**不是**恢复通道 |

PyVISA SOCKET 注意事项：
- 5024 的 `>>` 提示符后面**没有换行符**。设 `read_termination = "\n"` 时，查询在响应行换行处结束，残留的 `>>` 留在缓冲区里，会拼到**下一次**读取的开头。每次响应都要剥掉开头的 `>` 和空白字符（此机制由裸 socket 协议行为推得，待示波器恢复后实测验证）。
- 显式设置两个终止符：`write_termination = "\r\n"`、`read_termination = "\n"`。
- 超时单位为毫秒，超时抛 `pyvisa.errors.VisaIOError`（`VI_ERROR_TMO`）。与裸 socket 同规则：超时后关闭并重开连接。
- 二进制传输（`PRIN? PNG`）需关闭终止符并用 `read_raw()`/`read_bytes()`，还要手工剥提示符——截图场景裸 socket 更简单。

```python
import pyvisa
rm = pyvisa.ResourceManager("@py")
inst = rm.open_resource("TCPIP0::192.168.30.105::5024::SOCKET", timeout=5000)
inst.write_termination = "\r\n"
inst.read_termination = "\n"
resp = inst.query("*IDN?").lstrip("> \r\n\x00")   # 剥掉混入的提示符字符
inst.close()
```

**建议**：本项目自动化用 5024 裸 socket（与上文 PowerShell 模板及 `scope_lab.py` 一致）；PyVISA VXI-11 仅在示波器健康时做交叉验证。

### 4.2 PowerShell 通信模板

```powershell
$client = New-Object System.Net.Sockets.TcpClient
$client.Connect("192.168.30.105", 5024)
$stream = $client.GetStream()
$stream.ReadTimeout = 3000

function Read-UntilPrompt($stream) {
    $buffer = New-Object byte[] 8192
    $all = ""
    try {
        while ($true) {
            $read = $stream.Read($buffer, 0, $buffer.Length)
            if ($read -eq 0) { break }
            $chunk = [System.Text.Encoding]::ASCII.GetString($buffer, 0, $read)
            $all += $chunk
            if ($all -match ">>") { break }
        }
    } catch {}
    return $all
}

function Send-SCPI($stream, $cmd) {
    $bytes = [System.Text.Encoding]::ASCII.GetBytes($cmd + "`r`n")
    $stream.Write($bytes, 0, $bytes.Length)
    $stream.Flush()
    Start-Sleep -Milliseconds 600
    $raw = Read-UntilPrompt $stream
    $clean = $raw -replace "^\x00", ""
    $lines = $clean -split "`r?`n"
    $result = @()
    foreach ($line in $lines) {
        $t = $line.Trim()
        if ($t -eq "" -or $t -eq ">>" -or $t -eq $cmd) { continue }
        $result += $t
    }
    return ($result -join " | ")
}

$null = Read-UntilPrompt $stream   # 消费欢迎信息
# 发送命令...
$client.Close()
```

### 4.3 常用 SCPI 命令

#### 系统命令

| 命令 | 响应示例 | 说明 |
|------|---------|------|
| `*IDN?` | `Siglent Technologies,SDS2204X HD,...` | 设备识别 |
| `*CLS` | — | 清除状态 |
| `*RST` | — | 恢复默认配置（等效面板 Default 键） |
| `*OPC?` | `1` | 操作完成查询 |

> 手册（p.18）仅列出 `*IDN`/`*OPC`/`*RST` 三个通用命令；本固件实测还接受 `*CLS`、`*STB?`、`*SAV`/`*RCL`。`*ESE`/`*SRE`/`*TRG`/`*TST?` 未收录，状态查询用 `*STB?` 和 `SYST:ERR?`。

#### 通道配置

| 命令 | 响应示例 | 说明 |
|------|---------|------|
| `C1:TURN ON` | — | 开启通道（`OFF` 关闭） |
| `C1:VDIV 1` | — | 设置垂直档位为 1 V/div |
| `C1:VDIV?` | `C1:VDIV 1.00E+00V` | 查询垂直档位 |
| `C1:OFST 0` | — | 设置垂直偏移为 0 V（**关键**：非零偏移会把信号推出屏幕） |
| `C1:OFST?` | `C1:OFST 0.00E+00V` | 查询垂直偏移 |
| `C1:COUP DC` | — | 设置耦合方式（DC/AC/GND） |
| `C1:CPL?` | `C1:CPL D1M` | 查询耦合（注意是 `CPL?`，非 `COUP?`） |
| `C1:BWL FULL` | — | 带宽限制：FULL \| 20M \| 200M |
| `C1:INVT OFF` | — | 波形反转：ON \| OFF |
| `C1:UNIT V` | — | 垂直单位：V \| A \| W |
| `:CHAN1:VIS ON` | — | 显示/隐藏通道（**必须用 `:CHANn:` 完整形式**） |
| `:CHAN1:PROB VAL,1.00E+01` | — | 探头衰减比设为 10X（**必须用 `:CHANn:` 完整形式**） |
| `:CHAN1:PROB?` | `1.00E+01` | 查询探头衰减比 |
| `CHAN:REF OFFS` | — | 垂直参考策略：OFFS（偏移固定）\| POS（位置固定） |
| `:CHAN1:LAB ON` | — | 显示通道标签（手册 pp.46–47） |
| `:CHAN1:LAB:TEXT "WHITE"` | — | 设置标签文本，最长 20 字符，自动转大写 |
| `:CHAN1:SKEW 1.52E-09` | — | 探头偏移校正（deskew），范围 ±100 ns，用于多通道时序对齐 |

> **注意**：
> - `C1:TURN?`、`C1:SWIT?`、`C1:DISP?` 不是有效查询命令，返回空。
> - 探头衰减和通道显示命令**必须使用 `:CHANn:` 完整前缀**，`C1:PROB?` 和 `C1:VIS?` 短形式返回空。
> - 探头设置影响 VDIV 显示：10X 探头下 VDIV=1V，切换到 1X 后 VDIV 显示变为 0.1V（ADC 物理量程不变）。
> - SDS2204X HD 仅支持 1MΩ 输入阻抗，`C1:IMP?` 返回空。

#### 时基

| 命令 | 响应示例 | 说明 |
|------|---------|------|
| `TDIV 1E-5` | — | 设置水平档位 10 us/div（科学计数法可用） |
| `TDIV?` | `2.00E-05S` | 查询水平档位 |
| `HOR:POS?` | `50.00` | 查询水平位置（%） |

#### 触发

| 命令 | 响应示例 | 说明 |
|------|---------|------|
| `TRIG:EDGE:SOUR CHAN1` | — | 设置触发源（CHAN1~CHAN4） |
| `TRIG:EDGE:SOUR?` | `C1` | 查询触发源 |
| `TRIG:EDGE:LEV 0.7` | — | 设置触发电平（V） |
| `TRIG:EDGE:LEV?` | `7.00E-01` | 查询触发电平 |
| `TRIG:EDGE:SLOP POS` | — | 设置触发沿（POS/NEG） |
| `TRIG:EDGE:SLOP?` | `RISing` | 查询触发沿 |
| `TRIG:MODE AUTO` | — | 设置触发模式（AUTO/NORM/SINGLE） |
| `TRIG:MODE?` | `AUTO` | 查询触发模式 |
| `TRIG:FREQ?` | `1.234561E+04` | **硬件频率计**：读取触发源频率（Hz），只读，精度用 `FORM:DATA` 设置 |
| `TRIG:EDGE:IMP FIFT` | — | EXT 触发源阻抗：ONEMeg\|FIFTy（仅 EXT/EXT5 源有效） |
| `FORM:DATA CUSTom,7` | — | 设置查询响应数据精度：SINGle(7位)\|DOUBle(14位)\|CUSTom,1-64位（出厂默认仅 3 位有效数字，频率计等高精度读取前务必设置） |
| `TRIG:STAT?` | `Trig'd` | 查询触发状态（判断是否稳定触发） |
| `ASET` | — | **自动设置**：自动配置时基、电压、触发。手册（p.23）正式命令为 `:AUToset`（短形式 `AUT`），本固件同时接受 `ASET`；不建议用于 <100 Hz 信号 |

> **触发电平钳位（重要）**：固件将触发电平钳位在约 **1.1 × VDIV**（编程手册称 4.1×VDIV，但实际固件限制更严）。设置后务必用 `TRIG:EDGE:LEV?` 验证。
>
> | VDIV | 最大触发电平 |
> |------|-------------|
> | 0.5V | ~0.55V |
> | 1.0V | ~1.10V |
> | 2.0V | ~2.20V |
>
> 对于 3.3V 逻辑信号（VDIV=1V），触发电平设为 ~0.7V 即可。如需更高触发电平，先增大 VDIV。

#### 单次触发与运行控制

触发状态（`TRIG:STAT?`）：`Arm | Ready | Auto | Trig'd | Stop | Roll`

```
TRIG:MODE SINGLE    # 单次触发模式
TRIG:RUN            # 武装单次触发（等效按 RUN/SINGLE 键）
TRIG:STAT?          # 等待时 Arm/Ready → 捕获后 Stop
TRIG:STOP           # 停止采集并冻结波形（MODE 变为 STOP）
```

**已验证的单次触发流程**（连续 25kHz PWM 信号）：
```
TRIG:MODE SINGLE
TRIG:RUN              # 武装
# 轮询 TRIG:STAT? 直到 "Stop"（连续信号 <300ms 即触发）
C1:PAVA? FREQ         # 冻结波形上测量值仍可读
```

> **STOP 状态陷阱**：`TRIG:STOP` 会把 `TRIG:MODE?` 变成 `STOP`，此后单独发 `TRIG:RUN` 可能**无法**恢复采集。恢复方法：显式发送 `TRIG:MODE AUTO`，等待约 1s，查 `TRIG:STAT?` 应为 `Trig'd`。
>
> **SCPI 挂起警告**：不要在发送 `ASET` 后立即断开 TCP 连接——示波器 SCPI 服务（5024端口）在 ASET 处理期间可能挂起，拒绝新连接（Web 80 端口仍正常）。ASET 完成后（约 3-5s，用 `*OPC?` 轮询）再断开。若挂起，需等待数分钟或重启示波器。

#### 高级触发类型（手册 pp.402–460）

先用 `TRIG:TYPE` 切换触发类型，再配置对应参数：

```
TRIG:TYPE PULSE           # EDGE|PULSE|SLOPe|INTerval|PATTern|RUNT|WINDow|DROPout|VIDeo|QUALified|NTHEdge|DELay|SETuphold|IIC|SPI|UART|LIN|CAN...
TRIG:TYPE?                # 查询当前类型

# 脉宽（毛刺）触发——捕获异常 PWM 脉冲：
TRIG:PULS:SOUR C1         # 源通道
TRIG:PULS:POL POS         # 极性 POSitive|NEGative
TRIG:PULS:LEV 1.65        # 电平
TRIG:PULS:LIM LESS        # LESSthan|GREATerthan|INNer（区间内）|OUTer
TRIG:PULS:TLOW 1.0E-6     # 时间下界（秒）
TRIG:PULS:TUPP 4.0E-5     # 时间上界（配合 INNer/OUTer）

# 斜率触发——当两个电平之间的上升/下降时间超出范围时触发
# （可捕获 MOSFET 驱动退化导致的 PWM 缓慢边沿）：
TRIG:TYPE SLOPE
TRIG:SLOP:SOUR C1         # 源（仅模拟通道）
TRIG:SLOP:SLOP RIS        # RISing|FALLing|ALTernate
TRIG:SLOP:LLEV 0.3        # 低电平（V）
TRIG:SLOP:HLEV 0.9        # 高电平（V，必须大于 LLEV）
TRIG:SLOP:LIM LESS        # LESSthan|GREATerthan|INNer|OUTer（时间限制）
TRIG:SLOP:TLOW 2.0E-9     # 时间下界（秒；LIM=LESSthan 时无效）
TRIG:SLOP:TUPP 3.0E-8     # 时间上界（秒；LIM=GREATerthan 时无效）
TRIG:SLOP:COUP DC         # 耦合 DC|AC|LFREJect|HFREJect
TRIG:SLOP:HOLD OFF        # 释抑：OFF|EVENts|TIME（配合 HLDTime/HLDEVent/HSTart）

# 间隔触发——当相邻边沿间的时间超出范围时触发
# （捕获 PWM 频率抖动/丢脉冲）：
TRIG:TYPE INTERVAL
TRIG:INT:SOUR C1          # 源
TRIG:INT:SLOP RIS         # 边沿对：RISing|FALLing
TRIG:INT:LEV 0.7          # 电平
TRIG:INT:LIM GREAT        # LESSthan|GREATerthan|INNer|OUTer
TRIG:INT:TLOW 3.9E-5      # 时间下界（秒）
TRIG:INT:TUPP 4.1E-5      # 时间上界（秒）
TRIG:INT:COUP DC

# 超时触发——当超过设定时间没有边沿出现时触发
# （捕获 PWM 输出停振/固件挂死）：
TRIG:TYPE DROPOUT
TRIG:DROP:SOUR C1
TRIG:DROP:SLOP RIS        # 监视的边沿
TRIG:DROP:LEV 0.7
TRIG:DROP:TYPE EDGE       # EDGE（边沿超时）| STATe（状态超时）
TRIG:DROP:TIME 1.0E-4     # 超时时间，SDS2000X HD 范围 [2E-9, 20] 秒

# 欠幅触发——当脉冲只跨过一个电平而未跨过另一个时触发
# （捕获 PWM 高电平幅度不足）：
TRIG:TYPE RUNT
TRIG:RUNT:SOUR C1
TRIG:RUNT:POL POS         # 欠幅极性 POSitive|NEGative
TRIG:RUNT:LLEV 0.3        # 低电平（V）
TRIG:RUNT:HLEV 0.9        # 高电平（V）
TRIG:RUNT:LIM GREAT       # LESSthan|GREATerthan|INNer|OUTer（脉宽限制）
TRIG:RUNT:TLOW 2.0E-9
TRIG:RUNT:TUPP 2.0E+1

# 窗口触发——当信号进入或离开电压窗口时触发：
TRIG:TYPE WINDOW
TRIG:WIND:SOUR C1
TRIG:WIND:TYPE ABS        # ABSolute（绝对）| RELative（相对）窗口
TRIG:WIND:LLEV 0.2        # 窗口下限（V）
TRIG:WIND:HLEV 1.2        # 窗口上限（V）

# 码型触发——当多通道逻辑组合成立时触发
# （例如白灯 PWM 为高且黄灯 PWM 为低）：
TRIG:TYPE PATTERN
TRIG:PATT:INP H,L,X,X     # 各通道状态 H|L|X（无关项），顺序 C1..C4（,D0..D15）
TRIG:PATT:LEV C1,0.7      # 各源电平（查询：TRIG:PATT:LEV? C1）
TRIG:PATT:LIM GREAT       # 可选时间限定：LESSthan|GREATerthan|INNer|OUTer
TRIG:PATT:TLOW 1.0E-6
TRIG:PATT:TUPP 4.0E-5

# 延迟触发——当源 A 边沿到源 B 边沿的时间超出范围时触发
# （测量通道间 PWM 相移）：
TRIG:TYPE DELAY
TRIG:DEL:SOUR C1          # 源 A（参考边沿）
TRIG:DEL:SOUR2 C2         # 源 B（延迟边沿）
TRIG:DEL:SLOP RIS         # A 上边沿：RISing|FALLing
TRIG:DEL:SLOP2 RIS        # B 上边沿
TRIG:DEL:LEV C1,0.7       # 源 A 电平
TRIG:DEL:LEV2 C2,0.7      # 源 B 电平
TRIG:DEL:LIM INN          # LESSthan|GREATerthan|INNer|OUTer
TRIG:DEL:TLOW 0
TRIG:DEL:TUPP 2.0E-5

# 限定触发——仅当限定源 Q 满足状态/边沿条件时，源 E 上的边沿才触发
# （例如仅在水泵开启时捕获白灯 PWM 边沿）：
TRIG:TYPE QUALIFIED
TRIG:QUAL:ES C1           # 边沿源
TRIG:QUAL:ESL RIS         # 边沿斜率：RISing|FALLing
TRIG:QUAL:ELEV 0.7        # 边沿电平（V）
TRIG:QUAL:QS C3           # 限定源
TRIG:QUAL:QLEV 0.7        # 限定电平（V）
TRIG:QUAL:TYPE STATE,HIGH # STATe|STATE_DLY（+LOW|HIGH）或 EDGE|EDGE_DLY（+RISing|FALLing）
TRIG:QUAL:LIM INN         # *_DLY 类型的延迟限定
TRIG:QUAL:TLOW 3.0E-9
TRIG:QUAL:TUPP 3.0E-8

# 边沿触发补充（释抑可稳定复杂波形）：
TRIG:EDGE:HOLDoff TIMe    # 释抑模式：OFF|EVENts|TIMe
TRIG:EDGE:HLDTime 1E-4    # 释抑时间
TRIG:EDGE:HLDEVent 3      # 按事件数释抑
TRIG:EDGE:NREJ ON         # 噪声抑制（增大迟滞）
TRIG:EDGE:COUP DC         # 触发耦合 DC|AC|LFRejet|HFRejet

# 第 N 边沿触发——空闲时间后第 N 个边沿触发（手册 pp.538–548）。
# 可跳过脉冲串前导，在 PWM 脉冲序列深处触发：
TRIG:TYPE NTHEdge
TRIG:NEDG:SOUR C1         # 源

#### 触发通用设置（手册 pp.405–548）

以下三类设置对**所有**模拟触发类型（EDGE、PULSe、SLOPe、INTerval、DROPout、RUNT、WINDow、PATTern、NEDGe）语法完全一致——把 `<T>` 换成对应类型前缀（`EDGE|PULS|SLOP|INT|DROP|RUNT|WIND|PATT|NEDG`）。DELay 触发只有 COUPling。

```
TRIG:<T>:COUP DC          # 触发路径耦合：DC|AC|LFREJect|HFREJect
                          # AC 去除直流偏置；HFREJect 低通滤除射频噪声；
                          # LFREJect 高通滤除工频等低频干扰
TRIG:<T>:NREJ ON          # 噪声抑制 ON|OFF（增大迟滞，抗毛刺）
TRIG:<T>:HOLD TIMe        # 释抑模式：OFF|EVENts|TIMe
TRIG:<T>:HLDT 1.5E-8      # 释抑时间，SDS2000X HD 范围 [8ns, 30s]
TRIG:<T>:HLDEV 3          # 按事件数释抑 [1, 100000000]
TRIG:<T>:HST LAST_TRIG    # 释抑起点：LAST_TRIG（上次触发）| ACQ_START（采集开始）
```

仅手册中才有的类型专属补充：

```
# 窗口触发——电平有两种等效设置方式（任选一对即可定义窗口）：
TRIG:WIND:LLEV 0.2 / TRIG:WIND:HLEV 1.2     # 绝对下限/上限电平（V）
TRIG:WIND:CLEV 0.7 / TRIG:WIND:DLEV 0.5     # 或 中心电平+半窗宽（V），范围 ±(4.1*VDIV-OFST)

# 码型触发——各通道状态的逻辑组合：
TRIG:PATT:LOG AND         # AND|OR|NAND|NOR（默认 AND）

# 延迟触发——触发路径耦合（DELay 无释抑系列命令）：
TRIG:DEL:COUP DC          # DC|AC|LFREJect|HFREJect

# 第 N 边沿触发——独立的触发电平和噪声抑制：
TRIG:NEDG:LEV 0.5         # 触发电平（V），范围 ±(4.1*VDIV-OFST)
TRIG:NEDG:NREJ ON         # 噪声抑制 ON|OFF

#### 波形数据采集

示波器可返回原始采样数据用于编程分析：

```
WAV:SOUR C1           # 设置波形源通道
WAV:SOUR?             # 查询 → C1
WAV:PRE?              # WAVEDESC 描述符（含垂直增益、偏移、水平间隔）
WAV:DATA?             # 原始采样数据（IEEE 488.2 二进制块，~100KB）
```

- 响应前有一个 `0x00` 前导字节，然后是 `#<n><长度><数据>` 格式
- 8 位采样（0~255，128 为中心）
- 电压转换：`V = (sample - 128) × vertical_gain + vertical_offset`
- WAVEDESC 关键字段：offset 156 为垂直增益(V/count)，offset 160 为垂直偏移(V)，offset 176 为水平间隔(s/sample)

#### 数学运算（FUNCtion）

示波器支持波形数学运算，最多 2 个数学函数（FUNC1、FUNC2）。

```
FUNC1 ON              # 启用数学函数1
FUNC1:OPER ADD        # 运算类型：ADD|SUBTract|MULTiply|DIVision|FFT|INTegrate|DIFF|SQRT|ERES|AVERage|ABSolute|SIGN|IDENtity|NEGation|EXP|TEN|LN|LOG|INTErpolate|MAXHold|MINHold|FILTer
FUNC1:SOUR1 C1        # 源1（C1-C4, F1-F2）
FUNC1:SOUR2 C2        # 源2（用于加减乘除）
FUNC1:SCAL 1          # 数学波形垂直档位
FUNC1:OFST 0          # 数学波形垂直偏移
FUNC1 OFF             # 禁用数学
```

**FFT 示例：**
```
FUNC1 ON

FUNC1:SOUR1 C1
FUNC1:FFT:AUT NORM    # 自动设置：SPAN|PEAK|NORMal
FUNC1:FFT:HCEN?       # 中心频率
FUNC1:FFT:HSC?        # 水平档位（Hz/div）
FUNC1:FFT:SPAN?       # 频率跨度
FUNC1:FFT:MODE AVERage,16  # 采集方式：NORMal|MAXHold|AVERage[,4-1024]
FUNC1:FFT:UNIT DBVrms # 垂直单位：DBVrms|Vrms|DBm
FUNC1:FFT:WIND FLATtop  # 窗函数：RECTangle|BLACkman|HANNing|HAMMing|FLATtop（FLATtop 幅值精度最高）
FUNC1:FFT:SEAR:THR -40  # 峰值搜索阈值（单位随 FFT:UNIT）
FUNC1:FFT:SEAR:EXC 20   # 峰值搜索 excursion（高出邻近点的 dB 数）
FUNC1:FFT:SEAR:RES?     # 峰值列表 → Peaks,1,2.50E+04,1.20E+00;2,...（序号,频率,幅值）

**其他数学运算扩展**（手册 pp.209–246）：

FUNC1:AVER:NUM 128

#### 高级测量（MEASure:ADVanced）

高级测量系统（手册 pp.256–285）最多同时支持 12 个测量项（P1–P12），每项有独立信号源、统计和直接数值查询。**这是 `PAVA?` 返回空的参数（TOP/BASE/AMPL/PWID/NWID 等）的候选绕过方案**——尚未在本机实测验证。

```
MEAS:MODE ADV             # 测量模式：SIMPle | ADVanced
MEAS:ADV:LIN 12           # 显示项总数，范围 [1,12]
MEAS:ADV:P1 ON            # 启用测量项 P1
MEAS:ADV:P1:TYPE TOP      # 测量类型（完整参数表见下文）
MEAS:ADV:P1:SOUR1 C1      # 源 1：C<x>|Z<x>|F<x>|D<m>|REFA-REFD
MEAS:ADV:P1:SOUR2 C2      # 源 2（仅双源参数；延迟类只接受 C<x>）
MEAS:ADV:P1:VAL?          # 读取数值 → 3.30E+00（NR3 格式）
MEAS:ADV:STAT ON          # 启用统计（PAVA? 的 ,MAX/,MIN 后缀也需此项）
MEAS:ADV:P1:STAT? CURR    # 统计：ALL|CURRent|MEAN|MAXimum|MINimum|STDev|COUNt
MEAS:ADV:STAT:MAXC 1024   # 统计计数上限 [0,1024]，0 = 不限
MEAS:ADV:STAT:HISTOG ON   # 单项直方图（仅 M1 风格可用）
MEAS:ADV:STAT:RES         # 重置统计
MEAS:ADV:STYL M1          # 显示风格：M1（纵向+直方图）| M2（横向，无直方图）
```

完整 TYPE 列表：`PKPK|MAX|MIN|AMPL|TOP|BASE|LEVELX|CMEAN|MEAN|STDEV|VSTD|RMS|CRMS|MEDIAN|CMEDIAN|OVSN|FPRE|OVSP|RPRE|PER|FREQ|TMAX|TMIN|PWID|NWID|DUTY|NDUTY|WID|NBWID|DELAY|TIMEL|RISE|FALL|RISE10T90|FALL90T10|CCJ|PAREA|NAREA|AREA|ABSAREA|CYCLES|REDGES|FEDGES|EDGES|PPULSES|NPULSES|PHA|SKEW|FRR|FRF|FFR|FFF|LRR|LRF|LFR|LFF|PACArea|NACArea|ACArea|ABSACArea|PSLOPE|NSLOPE|TSR|TSF|THR|THF`。

双源参数（需 SOURce1 + SOURce2）：`PHA`（相位差）、`SKEW`（A 边沿减最近的 B 边沿）、`FRR/FRF/FFR/FFF`（首个边沿对）、`LRR/LRF/LFR/LFF`（首→末边沿对）、`DELAY`。可用于测量通道间 PWM 相移（如白灯与黄灯 PWM）。

**简单模式替代读取（MEASure:SIMPle）**——第二个候选绕过方案：

```
MEAS:SIMP:SOUR C1         # 简单测量源
MEAS:SIMP:ITEM TOP,ON     # 把 TOP 加入简单测量窗口
MEAS:SIMP:VAL? TOP        # 读取 → 3.30E+00
MEAS:SIMP:VAL? ALL        # 一次读取全部简单测量值（延迟类除外）
```

简单模式参数名与 `PAVA?` 一致，但上升/下降时间为 `RISE20T80`/`FALL80T20`（高级模式为 `RISE10T90`/`FALL90T10`）。

**测量阈值（MEASure:THReshold）**（手册 pp.281–285）：

阈值定义了时间/占空比类测量使用的参考电平：

```
MEAS:THR:SOUR C1              # 阈值源：C<x>|Z<x>|F<x>|REFA-REFD
MEAS:THR:TYPE PERC            # PERCent（百分比）| ABSolute（绝对电压）
MEAS:THR:PERC 80,45,10        # 高、中、低阈值百分比（默认 90,50,10）
MEAS:THR:ABS 3.00,1.00,-1.50  # 高、中、低阈值电压（TYPE=ABSolute 时）
```

测量固定逻辑电平间的 PWM 时建议用 ABSolute 阈值，避免 PER/PWID/DUTY 随幅度变化而漂移。

#### 测量门控（MEASure:GATE）

将自动测量限制在门 A 与门 B 之间的时间窗口内（手册 pp.275–277），适用于只测量长捕获中的某个 PWM 脉冲。

```
MEAS:GATE ON              # 启用测量门控（查询：MEAS:GATE? → ON）
MEAS:GATE:GA -1.00E-07    # 门 A 位置（秒），范围 ±grid/2 × 时基
MEAS:GATE:GB 1.00E-07     # 门 B 位置（秒）
```

> 注意：GA 不能大于 GB，越界值会被自动钳位到另一门的位置。

#### 参考波形（REF）

将通道波形快照保存为参考叠加层，用于与待测信号目视比对（手册 pp.316–321）。共 4 个槽位：REFA–REFD。

```
REFA:DATA SAVE,C1         # 将 C1 波形保存到 REFA
REFA:DATA LOAD            # 在屏幕上显示 REFA（UNLoad 隐藏）
REFA:DATA:SOUR?           # 查询已保存的源 → C1
REFA:DATA:SCAL 1.00E-01   # 参考波形显示垂直档位
REFA:DATA:POS 2.00E-01    # 参考波形显示垂直偏移
REFA:LAB ON               # 显示标签
REFA:LAB:TEXT "REFA"      # 设置标签文本（最长 20 字符）
```

典型流程：捕获已知良好的 25 kHz PWM → `REFA:DATA SAVE,C1` → 之后 `REFA:DATA LOAD`，将可疑信号与黄金参考比对。光标源也支持 REFA–REFD（`CURS:SOUR1 REFA`）。

#### 存储波形（MEMory，M1–M4）

存储波形是独立的已存轨迹（手册 pp.285–294）。与 REF 叠加层不同，每个 M 有独立的水平/垂直档位与位置，可将单个脉冲的快速放大视图与实时波形并排显示。

```
MEM1:IMP C1               # 导入源到 M1：C<x>|Z<x>|F<x>|M<x>|"<路径>.bin"
MEM1:SWIT ON              # 显示 M1（查询：MEM1:SWIT? → ON）
MEM1:HOR:SCAL 1.00E-07    # 水平档位 100 ns/div（独立于实时 TDIV）
MEM1:HOR:POS 1.00E-05     # 相对触发点的水平位置
MEM1:HOR:SYNC ON          # M1 水平参数与导入源同步
MEM1:VERT:SCAL 1.00E-01   # 垂直档位
MEM1:VERT:POS 1.00E-01    # 垂直位置
MEM1:LAB ON               # 显示标签；MEM1:LAB:TEXT "PWM_ref"（最长 20 字符）
```

#### 响应格式

- 查询成功：`C1:PAVA FREQ,2.50E+04Hz`
- 无信号：`C1:PAVA FREQ,****` 或空字符串
- 无效命令：返回空（命令被静默忽略）

### 4.4 注意事项

1. **单连接单通道测量最稳定**：在同一 TCP 连接中对多个通道连续发送测量命令，可能导致示波器无响应。建议每个通道使用独立连接，或在命令间留足延时（≥600ms）。
2. **超时处理**：`ReadTimeout` 设为 2000~3000ms。若某命令超时，关闭连接重新建立，不要复用超时后的连接。
3. **换行符**：使用 `\r\n` 作为命令终止符。
4. **测量值为科学计数法**：如 `2.50E+04` 表示 25000，`4.96E+01` 表示 49.6。

### 4.6 波形数据读取（`WAV:DATA?`）

可通过 SCPI 读取原始波形采样点做程序化分析，无需截图（协议见编程手册 p663-678）：

```
WAV:SOUR C1           # 波形源（C1-C4，F1-F2 数学，D0-D15 数字）
WAV:WIDT WORD         # SDS2000X HD 必须设 WORD（12-bit ADC）；WORD=每点 16 位，高字节先传
WAV:STAR 0            # 起始点
WAV:INT 1             # 抽点间隔（抽取）
WAV:POIN 20000        # 传输点数
WAV:MAXP?             # 单次最大可传点数
WAV:PRE?              # WAVEDESC 描述块："#9<9位数字>" + 346 字节
WAV:DATA?             # 采样数据块："#N<N位数字>" + 数据 + 结尾 0x0A 0x0A
```

**SDS2000X HD 转换常数**（手册 p675 表 1）：`code_per_div = 480`，中心码 `2047`，满码 `4096`（12-bit）。

- WORD 模式重组：`data16 = byte[2i+1]*256 + byte[2i]`，再 `code = data16 >> 4`；`code > 2047` 时 `code -= 4096`（转有符号）。
- 电压换算：`V = code * (vdiv / code_per_div) - voffset`
  - `vdiv` = WAVEDESC 偏移 156 处 float（不含探头衰减的垂直档位）
  - `voffset` = 偏移 160 处 float；`code_per_div` = 偏移 164 处 float（本机应读出 480）
- 时间换算：`t = -delay - (timebase * 10/2) + index * interval`
  - `delay` = 偏移 180 处 double（触发偏移，秒）；`interval` = 偏移 176 处 float（采样间隔）
  - `timebase` = 偏移 324 处 short（枚举值，见手册 p672 表 2）
- 数据量大（100KB+），务必写文件，不要打印到控制台；必须用原始字节读取，不能用 ReadLine()。

**序列模式分帧传输**（手册 p679）：当 `:ACQuire:SEQuence ON` 时，用 `WAV:SEQ` 选择 `WAV:DATA?` 返回哪一帧：

```
WAV:SEQ 3,0       # 只传第 3 帧
WAV:SEQ 0,1       # 从第 1 帧开始传全部帧（总量超内存时须分片读）
WAV:SEQ?          # -> <帧>,<起始>。默认：序列开 -> 1；序列+历史开 -> 当前帧；否则 4294967295
```

分片所需的帧数信息在 `WAV:PRE?` 的 WAVEDESC 字段：read_frames（0x90-0x93）与 sum_frames（0x94-0x97）。

TRIG:IIC:LIM EQU          # 数据比较（COND=EEPRom 时）：EQUal|GREaterthan|LESSthan

条件说明：`EEPRom` 在 EEPROM 读操作（1010xxx 地址 + LIM 数据比较）时触发；`DLENgth` 在传输达到指定字节数时触发；`NACK` 在缺少 ACK 时触发——可用于捕获 I2C 设备无响应故障。

**SPI 触发**（手册 pp.573–589）——触发 SPI 总线事务：

```

TRIG:SPI:TTYP MOSI        # 触发数据线：MISO|MOSI
TRIG:SPI:CLKS C1          # CLK 源（C<x>|D<n>）
TRIG:SPI:CLKT 1.65        # CLK 阈值 V
TRIG:SPI:MOSIS C2         # MOSI 源；MISO 用 MISOSource/MISOThreshold
TRIG:SPI:MOSIT 1.65       # MOSI 阈值 V
TRIG:SPI:CSTY CS          # 帧检测方式：CS|NCS|TIMeout[,<时间 1E-7..5E-3 秒>]

TRIG:SPI:BIT MSB          # 位序：LSB|MSB
TRIG:SPI:DLEN 8           # 数据长度（位）[4,96]

## 5. PWM 测量验证流程

### 5.1 理论占空比计算

实际 PWM 占空比由两级变换决定：

1. **功率校准**（`calibratePower`）：亮度% → 查表插值 → PWM%
2. **minDuty 偏移**（`setPwm`）：PWM% → 实际占空比

```
实际占空比 = (maxDuty - minDuty)/100 * 1023 * (calibratePower(brightness) / 100) / 1023 * 100 + minDuty
```

简化：`实际占空比 ≈ minDuty + (maxDuty - minDuty) * calibratePower(brightness) / 100`

### 5.2 验证步骤

1. 查询设备状态：`http://192.168.30.74/status?devicepwd=pengping&mode=get`
2. 读取 `whiteApplied`、`yellowApplied`、`fanSpeed`、`pumpSpeed`
3. 计算理论占空比
4. 用 SCPI 测量各通道 FREQ 和 DUTY
5. 对比实测值与理论值

> 上述步骤已封装为 `python scripts\scope_lab.py pwm`：自动拉取 `/status`、逐通道打开并测量 FREQ/DUTY、打印对照表并截图 `pwm.png`。
>
> **2026-11-10 09:01 DUT 快照**（示波器仍卡死，仅作基准）：`onOffStatus=true`、`brightness=79`、`colorTemperature=50`、`whiteApplied=yellowApplied=39.5`、`fanSpeed=pumpSpeed=0`；四路频率均 25000 Hz；min/max = 白 6~100%、黄 5~100%、泵 15~100%、扇 10~100%。按线性近似（未计 23 点功率校准表）预期：白 `6+94×0.395≈43.1%`、黄 `5+95×0.395≈42.5%`；泵/扇为 0 时 C3/C4 只可能出现串扰信号。

## 6. 完整测量工作流（25kHz PWM 配置 + 截图）

端到端流程：配置示波器测量 25kHz PWM 信号，读取测量值，截图存档。

```

:CHAN2:PROB VAL,1.00E+01

# 3. 设置时基（10us/div，40us 周期占约 4 格）

# 4. 配置触发（C1 上升沿，自动）

C1:MEAS FREQ,ON
C1:MEAS DUTY,ON
C1:MEAS PKPK,ON
C1:MEAS PER,ON
C1:MEAS RMS,ON
C1:MEAS MAX,ON
C1:MEAS MIN,ON
C1:MEAS RISE,ON
C1:MEAS FALL,ON

C1:PAVA? MIN             # → -1.42E-01 V

**裸 RFB 探测（无需 VNC 客户端）**：约 40 行代码即可给示波器“指纹”：横幅 `RFB 003.008`、安全类型 `[1]`（None —— **无认证**，局域网内任何人都能看/控屏幕）、ServerInit 为 `1024×600, bpp=16, depth=16, RGB565（max 31/63/31，shift 11/5/0）`、桌面名 `Instrument`。健康时它可作为独立于 `PRIN?` 的帧缓冲截图通道；卡死时握手全部成功但帧更新请求超时——这是一个干净、无侵入的卡死判据，不会触碰 SCPI 服务（但见上表：不要把“探测”变成“反复请求”，一次请求就能让 5900 彻底消失）。

**Web SCPI 代理的接口细节**（卡死时唯一还能说话的 HTTP 通道，也可用于健康时诊断）：
```
POST http://192.168.30.105/device_read_write.php
Content-Type: application/x-www-form-urlencoded
cmd={"cmd":"*IDN?","type":"ds","to":"127.0.0.1"}     (JSON 字符串，需 URL 编码)
action=excutescpicmds
```
返回体是 `\r\n` 分隔的三段 JSON：`{"success":true}` / `{"retCount":1}` / `{"cmdrslt":"..."}`。Web 栈为 lighttpd/1.4.35 + PHP/5.4.5，`/device_read_write.php` 之外没有 `/reboot`、`/restart`、`/system/reboot` 等任何重启端点（全部 404），因此 HTTP 层无法自救。PowerShell 的 `Invoke-WebRequest` 会带上 `Expect: 100-continue` 而被 lighttpd 以 **417** 拒绝，改用 `curl.exe --data-urlencode` 或关闭 `ServicePoint.Expect100Continue`。

**恢复：只能物理断电重启。** SCPI 虽有 `SYSTem:REBoot` 命令但无法送达（代理报设备未连接；Web 服务器无重启端点）；VNC 输入事件同样无法送达（RFB 握手能完成、甚至能收到 ServerInit，但画面永远不会刷新，说明 UI 合成器与 SCPI 应用一起冻结）。怀疑卡死时先按上表确认，再排查网络；确认后断电重启并轮询 5024 端口等待恢复（开机约 1–2 分钟）。

## 9. 串行总线解码（DECode）子系统（手册 pp.71–172）

示波器提供两条独立解码总线（BUS1、BUS2）。使用流程：打开解码总开关 → 为总线选择协议 → 配置源通道与阈值 → 用 `:DECode:BUS<n>:RESult?` 读取文本化解码结果。

### 9.1 全局与总线控制

```
:DECode ON                  # 解码总开关：ON|OFF
:DECode:LIST D1             # 屏幕解码列表：OFF|D1|D2
:DECode:LIST:LINE 6         # 列表显示行数 [1,7]
:DECode:LIST:SCRoll 3       # 列表选中行
:DECode:BUS1 ON             # 单条总线开关
:DECode:BUS1:PROTocol IIC   # 协议：IIC|SPI|UART|CAN|LIN|FLEXray|CANFd|IIS|M1553
:DECode:BUS1:FORMat HEX     # 显示格式：BINary|DECimal|HEX|ASCii
:DECode:BUS1:COPY FROMtrigger   # 从触发设置同步到解码（TOTRigger 为反向）
:DECode:BUS1:RESult?        # 读取解码结果文本；首行为表头，帧之间以 ';' 分隔
                             # 例："lin,sync,id,parity,data,checksum;\n0x55,0x06,0,0x54\s0x5F,0x46;"
```

短命令前缀为 `DEC`。注意 CAN/LIN/FLEXray/CANFd/IIS/M1553 解码在部分机型上需要选件授权。

### 9.2 阈值规则（所有协议通用）

SDS2000X HD 阈值范围：`[-4.1×VDIV − OFST, +4.1×VDIV − OFST]`（与触发电平同族钳位——设置后用 `?` 查询验证）。

### 9.3 IIC 解码（pp.80–86）

```
:DECode:BUS1:IIC:SCLSource C1      # SCL 源：C1..C4（带 MSO 时可用 D0..D15）
:DECode:BUS1:IIC:SCLThreshold 1.00E+00
:DECode:BUS1:IIC:SDASource C2
:DECode:BUS1:IIC:SDAThreshold 1.00E+00
:DECode:BUS1:IIC:RWBit ON          # 结果中包含 R/W 位
```

### 9.4 SPI 解码（pp.87–101）

```
:DECode:BUS1:SPI:CLKSource C1      # 时钟源 + :CLKThreshold
:DECode:BUS1:SPI:MOSISource C2     # MOSI 源 + :MOSIThreshold
:DECode:BUS1:SPI:MISOSource C3     # MISO 源 + :MISOThreshold
:DECode:BUS1:SPI:CSTYpe CS         # 帧定界：NCS|CS|TIMeout[,<1E-7..5E-3 秒>]
:DECode:BUS1:SPI:CSSource C4       # CS 源 + :CSThreshold（或 NCSSource/NCSThreshold）
:DECode:BUS1:SPI:DLENgth 8         # 数据字长 [4,32]
:DECode:BUS1:SPI:BITorder MSB      # 位序 LSB|MSB
:DECode:BUS1:SPI:LATChedge RISing  # 采样沿 RISing|FALLing
```

### 9.5 UART 解码（pp.102–112）

```
:DECode:BUS1:UART:RXSource C1      # RX 源 + :RXThreshold（TX 用 TXSource/TXThreshold）
:DECode:BUS1:UART:BAUD 115200bps   # 600..115200bps 预设 | CUSTom[,300..20000000]
:DECode:BUS1:UART:DLENgth 8        # 数据位 [5,8]
:DECode:BUS1:UART:STOP 1           # 停止位：1|1.5|2
:DECode:BUS1:UART:PARity NONE      # 校验：NONE|ODD|EVEN|MARK|SPACe
:DECode:BUS1:UART:IDLE HIGH        # 空闲电平：LOW|HIGH
:DECode:BUS1:UART:BITorder LSB     # 位序
```

### 9.6 CAN / LIN / FlexRay / CAN FD 解码（pp.113–129）

```
:DECode:BUS1:CAN:SOURce C1         # + :DECode:BUS1:CAN:THReshold 1.5
:DECode:BUS1:CAN:BAUD 500kbps      # 5k..1M 预设 | CUSTom[,5000..1000000]
:DECode:BUS1:LIN:SOURce C1         # + :DECode:BUS1:LIN:THReshold 1.5
:DECode:BUS1:LIN:BAUD 19200bps     # 600..19200 预设 | CUSTom[,300..20000000]
:DECode:BUS1:FLEXray:SOURce C1     # + :DECode:BUS1:FLEXray:THReshold 1.5
:DECode:BUS1:FLEXray:BAUD 10Mbps   # 2500k|5M|10M | CUSTom[,1000000..20000000]
:DECode:BUS1:CANFd:SOURce C1       # + :DECode:BUS1:CANFd:THReshold 1.5
:DECode:BUS1:CANFd:BAUDNominal 500kbps  # 标称波特率 10k..1M 预设 | CUSTom[,10000..1000000]
:DECode:BUS1:CANFd:BAUDData 2Mbps       # 数据段波特率 500k..10M 预设 | CUSTom[,100000..10000000]
```

### 9.7 IIS 音频解码（pp.130–143）

```
:DECode:BUS1:IIS:BCLKSource C1     # 位时钟 + :BCLKThreshold
:DECode:BUS1:IIS:WSSource C2       # 字选择 + :WSTHreshold
:DECode:BUS1:IIS:DSource C3        # 数据 + :DTHReshold
:DECode:BUS1:IIS:AVARiant I2S      # 对齐格式：I2S|LJ|RJ
:DECode:BUS1:IIS:LATChedge RISing  # BCLK 采样沿
:DECode:BUS1:IIS:DLENgth 16        # 数据位宽 [1,32]
:DECode:BUS1:IIS:SBIT 0            # 起始位 [0,31]
:DECode:BUS1:IIS:BITorder MSB
:DECode:BUS1:IIS:LCH LOW           # WS 电平含义为"左声道"：LOW|HIGH
:DECode:BUS1:IIS:ANNotate ALL      # 标注声道：ALL|LEFT|RIGHt
```

### 9.8 M1553 解码（pp.144–146，选件）

```
:DECode:BUS1:M1553:SOURce C1
:DECode:BUS1:M1553:LTHReshold -1.00E+00   # 下阈值（必须小于上阈值）
:DECode:BUS1:M1553:UTHReshold 1.00E+00    # 上阈值
```

### 9.9 SENT 解码（pp.148–157，选件）

```
:DECode:BUS1:SENT:SOURce C1        # + :DECode:BUS1:SENT:THReshold 1.5
:DECode:BUS1:SENT:FORMat NIBBles   # 报文格式：NIBBles|FSIGnal|SSERial|ESERial
:DECode:BUS1:SENT:CLOCk 3.00E-06   # 时钟节拍 [500E-9, 300E-6] 秒
:DECode:BUS1:SENT:IDLE LOW         # 空闲电平
:DECode:BUS1:SENT:LENGth 6         # 数据半字节数
:DECode:BUS1:SENT:CRC ON           # ON=2010 版 CRC，OFF=2008 版
:DECode:BUS1:SENT:PPULse ON        # 暂停脉冲
```

### 9.10 Manchester 解码（pp.159–172，选件）

```
:DECode:BUS1:MANChester:SOURce C1  # + :DECode:BUS1:MANChester:THReshold 1.5
:DECode:BUS1:MANChester:BAUD 9600  # NR1 格式 [500, 5000000]（纯数字，无 "bps" 后缀）
:DECode:BUS1:MANChester:POLarity RISing  # 用上升沿编码逻辑 1：RISing|FALLing
:DECode:BUS1:MANChester:IDLE LOW
:DECode:BUS1:MANChester:IBITs 8    # 空闲位 [2,32]
:DECode:BUS1:MANChester:STARt 1    # 起始沿序号 [1,32]
:DECode:BUS1:MANChester:SSIZe 0    # 同步头长度 [0,32]
:DECode:BUS1:MANChester:HSIZe 0    # 帧头长度 [0,32]
:DECode:BUS1:MANChester:TSIZe 0    # 帧尾长度 [0,32]
:DECode:BUS1:MANChester:WSIZe 8    # 字长 [2,8]
:DECode:BUS1:MANChester:DSIZe 16   # 每帧字数 [1,255]
:DECode:BUS1:MANChester:DISPlay WORD   # 结果显示：WORD|BIT
:DECode:BUS1:MANChester:BITorder MSB
```

## 10. 采集（ACQuire）子系统（手册 pp.25–38）

```
:ACQuire:TYPE NORMal          # 采集类型：NORMal|PEAK|AVERage[,次数]|ERES[,位数]
                              #   AVERage 次数：4|16|32|64|128|256|512|1024
                              #   ERES 位数：0.5|1.0|1.5|2.0|2.5|3.0（数字矩形滤波，慢扫描降噪）
                              #   注意：序列模式（SEQuence ON）下 AVERage/ERES 不可用
:ACQuire:MODE YT              # 采集模式：YT|XY|ROLL（ROLL=走纸模式，适合慢速信号）
:ACQuire:MMANagement AUTO     # 存储管理：AUTO（最大采样率）|FSRate（固定采样率）|FMDepth（固定深度）
:ACQuire:MDEPth 200M          # SDS2000X HD：单通道 {20k|200k|2M|20M|200M}，双通道 {10k|100k|1M|10M|100M}
                              #   打开数字通道 / AVERage/ERES / ROLL 模式会降低可用深度
:ACQuire:SRATe 5.00E9         # 固定采样率模式下的采样率；超出可设值时自动匹配
:ACQuire:AMODe FAST           # 波形捕获率：FAST|SLOW（FAST 有助于捕获异常）
:ACQuire:INTerpolation ON     # 插值：ON=sinx/x（sinc），OFF=线性
:ACQuire:RESolution 10Bits    # ADC 分辨率：8Bits|10Bits（SDS2000X Plus / HD）
:ACQuire:SEQuence ON          # 序列（分段存储）采集模式，快速重新触发捕获突发
:ACQuire:SEQuence:COUNt 100   # 段数（上限取决于存储深度/时基）
:ACQuire:CSWeep               # 仅命令：清除扫描并重新开始采集（等效面板 Clear Sweeps）
:ACQuire:NUMAcq?              # 查询：启动以来的采集次数（改动设置会清零）
:ACQuire:POINts?              # 查询：当前波形采样点数，如 1.25E+08
```

短命令前缀为 `ACQ`。
