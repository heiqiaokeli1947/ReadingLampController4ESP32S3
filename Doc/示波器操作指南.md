# Siglent SDS2204X HD 示波器操作指南

本指南记录 ReadingLampController4ESP32S3 项目中使用 Siglent SDS2204X HD 示波器测量 PWM 信号的操作方法，包括 Web 界面操作和 SCPI 远程控制两种方式。

## 2. 探头连接

本项目 PWM 信号引脚与示波器通道的对应关系：

| 示波器通道 | ESP32-S3 GPIO | 信号 | 配置频率 | minDuty | maxDuty |
|-----------|---------------|------|---------|---------|---------|
| CH1 | GPIO16 | 白灯 PWM (whitePwm) | 25 kHz | 6% | 100% |
| CH2 | GPIO17 | 黄灯 PWM (yellowPwm) | 25 kHz | 5% | 100% |
| CH3 | GPIO18 | 水泵 PWM (pumpPwm) | 25 kHz | 15% | 100% |
| CH4 | GPIO8 | 风扇 PWM (fanPwm) | 25 kHz | 15% | 100% |

> 注意：CH3/CH4 在风扇/水泵关闭时可能检测到来自 LED PWM 走线的电磁串扰信号。判断是否为真实信号的方法：关灯后若信号消失，则为串扰而非真实 PWM 输出。

## 4. SCPI 远程控制（推荐）

### 4.1 连接方式

示波器提供两个 SCPI 端口：

| 端口 | 协议 | 特点 |
|------|------|------|
| 5025 | Raw TCP | 命令直接响应，但超时后连接易卡死 |
| **5024** | Telnet 风格 | 带 `>>` 提示符，超时后恢复能力强，**推荐使用** |

### 4.2 PowerShell 通信模板

```powershell
$client = New-Object System.Net.Sockets.TcpClient
$client.Connect("192.168.30.105", 5024)
$stream = $client.GetStream()
$stream.ReadTimeout = 3000

function Read-UntilPrompt($stream) {
    $buffer = New-Object byte[] 8192
    $all = ""
    try {
        while ($true) {
            $read = $stream.Read($buffer, 0, $buffer.Length)
            if ($read -eq 0) { break }
            $chunk = [System.Text.Encoding]::ASCII.GetString($buffer, 0, $read)
            $all += $chunk
            if ($all -match ">>") { break }
        }
    } catch {}
    return $all
}

function Send-SCPI($stream, $cmd) {
    $bytes = [System.Text.Encoding]::ASCII.GetBytes($cmd + "`r`n")
    $stream.Write($bytes, 0, $bytes.Length)
    $stream.Flush()
    Start-Sleep -Milliseconds 600
    $raw = Read-UntilPrompt $stream
    $clean = $raw -replace "^\x00", ""
    $lines = $clean -split "`r?`n"
    $result = @()
    foreach ($line in $lines) {
        $t = $line.Trim()
        if ($t -eq "" -or $t -eq ">>" -or $t -eq $cmd) { continue }
        $result += $t
    }
    return ($result -join " | ")
}

$null = Read-UntilPrompt $stream   # 消费欢迎信息
# 发送命令...
$client.Close()
```

#### 通道配置

| 命令 | 响应示例 | 说明 |
|------|---------|------|
| `C1:TURN ON` | — | 开启通道（`OFF` 关闭） |
| `C1:VDIV 1` | — | 设置垂直档位为 1 V/div |
| `C1:VDIV?` | `C1:VDIV 1.00E+00V` | 查询垂直档位 |
| `C1:OFST 0` | — | 设置垂直偏移为 0 V（**关键**：非零偏移会把信号推出屏幕） |
| `C1:OFST?` | `C1:OFST 0.00E+00V` | 查询垂直偏移 |
| `C1:COUP DC` | — | 设置耦合方式（DC/AC/GND） |
| `C1:CPL?` | `C1:CPL D1M` | 查询耦合（注意是 `CPL?`，非 `COUP?`） |
| `C1:BWL FULL` | — | 带宽限制：FULL \| 20M \| 200M |
| `C1:INVT OFF` | — | 波形反转：ON \| OFF |
| `C1:UNIT V` | — | 垂直单位：V \| A \| W |
| `:CHAN1:VIS ON` | — | 显示/隐藏通道（**必须用 `:CHANn:` 完整形式**） |
| `:CHAN1:PROB VAL,1.00E+01` | — | 探头衰减比设为 10X（**必须用 `:CHANn:` 完整形式**） |
| `:CHAN1:PROB?` | `1.00E+01` | 查询探头衰减比 |
| `CHAN:REF OFFS` | — | 垂直参考策略：OFFS（偏移固定）\| POS（位置固定） |

> **注意**：
> - `C1:TURN?`、`C1:SWIT?`、`C1:DISP?` 不是有效查询命令，返回空。
> - 探头衰减和通道显示命令**必须使用 `:CHANn:` 完整前缀**，`C1:PROB?` 和 `C1:VIS?` 短形式返回空。
> - 探头设置影响 VDIV 显示：10X 探头下 VDIV=1V，切换到 1X 后 VDIV 显示变为 0.1V（ADC 物理量程不变）。
> - SDS2204X HD 仅支持 1MΩ 输入阻抗，`C1:IMP?` 返回空。

#### 触发

| 命令 | 响应示例 | 说明 |
|------|---------|------|
| `TRIG:EDGE:SOUR CHAN1` | — | 设置触发源（CHAN1~CHAN4） |
| `TRIG:EDGE:SOUR?` | `C1` | 查询触发源 |
| `TRIG:EDGE:LEV 0.7` | — | 设置触发电平（V） |
| `TRIG:EDGE:LEV?` | `7.00E-01` | 查询触发电平 |
| `TRIG:EDGE:SLOP POS` | — | 设置触发沿（POS/NEG） |
| `TRIG:EDGE:SLOP?` | `RISing` | 查询触发沿 |
| `TRIG:MODE AUTO` | — | 设置触发模式（AUTO/NORM/SINGLE） |
| `TRIG:MODE?` | `AUTO` | 查询触发模式 |
| `TRIG:STAT?` | `Trig'd` | 查询触发状态（判断是否稳定触发） |
| `ASET` | — | **自动设置**：自动配置时基、电压、触发 |

> **触发电平钳位（重要）**：固件将触发电平钳位在约 **1.1 × VDIV**（编程手册称 4.1×VDIV，但实际固件限制更严）。设置后务必用 `TRIG:EDGE:LEV?` 验证。
>
> | VDIV | 最大触发电平 |
> |------|-------------|
> | 0.5V | ~0.55V |
> | 1.0V | ~1.10V |
> | 2.0V | ~2.20V |
>
> 对于 3.3V 逻辑信号（VDIV=1V），触发电平设为 ~0.7V 即可。如需更高触发电平，先增大 VDIV。

#### 单次触发与运行控制

触发状态（`TRIG:STAT?`）：`Arm | Ready | Auto | Trig'd | Stop | Roll`

```
TRIG:MODE SINGLE    # 单次触发模式
TRIG:RUN            # 武装单次触发（等效按 RUN/SINGLE 键）
TRIG:STAT?          # 等待时 Arm/Ready → 捕获后 Stop
TRIG:STOP           # 停止采集并冻结波形（MODE 变为 STOP）
```

**已验证的单次触发流程**（连续 25kHz PWM 信号）：
```
TRIG:MODE SINGLE
TRIG:RUN              # 武装
# 轮询 TRIG:STAT? 直到 "Stop"（连续信号 <300ms 即触发）
C1:PAVA? FREQ         # 冻结波形上测量值仍可读
```

> **STOP 状态陷阱**：`TRIG:STOP` 会把 `TRIG:MODE?` 变成 `STOP`，此后单独发 `TRIG:RUN` 可能**无法**恢复采集。恢复方法：显式发送 `TRIG:MODE AUTO`，等待约 1s，查 `TRIG:STAT?` 应为 `Trig'd`。
>
> **SCPI 挂起警告**：不要在发送 `ASET` 后立即断开 TCP 连接——示波器 SCPI 服务（5024端口）在 ASET 处理期间可能挂起，拒绝新连接（Web 80 端口仍正常）。ASET 完成后（约 3-5s，用 `*OPC?` 轮询）再断开。若挂起，需等待数分钟或重启示波器。

C1:MEAS PER,ON       # 周期
C1:PAVA? PER         # 读取 → C1:PAVA PER,4.00E-05s
C1:PAVA? RMS         # 读取有效值 → C1:PAVA RMS,1.24E+00V

C1:MEAS FALL,ON      # 下降时间
C1:PAVA? FALL        # 读取 → C1:PAVA FALL,4.70E-09s

**SCPI 可读取的测量参数：**

| 参数 | 说明 | 示例 |
|------|------|------|
| `FREQ` | 频率 | 2.50E+04 Hz |
| `DUTY` | 占空比 | 9.48E+01 % |

#### 波形数据采集

示波器可返回原始采样数据用于编程分析：

```
WAV:SOUR C1           # 设置波形源通道
WAV:SOUR?             # 查询 → C1
WAV:PRE?              # WAVEDESC 描述符（含垂直增益、偏移、水平间隔）
WAV:DATA?             # 原始采样数据（IEEE 488.2 二进制块，~100KB）
```

- 响应前有一个 `0x00` 前导字节，然后是 `#<n><长度><数据>` 格式
- 8 位采样（0~255，128 为中心）
- 电压转换：`V = (sample - 128) × vertical_gain + vertical_offset`
- WAVEDESC 关键字段：offset 156 为垂直增益(V/count)，offset 160 为垂直偏移(V)，offset 176 为水平间隔(s/sample)

#### 响应格式

- 查询成功：`C1:PAVA FREQ,2.50E+04Hz`
- 无信号：`C1:PAVA FREQ,****` 或空字符串
- 无效命令：返回空（命令被静默忽略）
- **所有响应前有一个 `0x00` 空字节**：使用 `StreamReader.ReadLine()` 时会出现前导字符，需用 `$resp.TrimStart([char]0)` 去除。

### 4.4 注意事项

1. **单连接单通道测量最稳定**：在同一 TCP 连接中对多个通道连续发送测量命令，可能导致示波器无响应。建议每个通道使用独立连接，或在命令间留足延时（≥600ms）。
2. **超时处理**：`ReadTimeout` 设为 2000~3000ms。若某命令超时，关闭连接重新建立，不要复用超时后的连接。
3. **换行符**：使用 `\r\n` 作为命令终止符。
4. **测量值为科学计数法**：如 `2.50E+04` 表示 25000，`4.96E+01` 表示 49.6。

### 4.5 SCPI 截图（`PRIN?`，推荐）

`PRIN?` 直接通过 SCPI  socket 返回屏幕图像字节流，取代脆弱的"浏览器点 ScreenShot + 另存为对话框"流程（编程手册 p22、p755）：

```
PRIN? BMP               # 返回 BMP 原始图像字节
PRIN? PNG               # 返回 PNG 原始图像字节
```

- 响应为原始二进制图像数据（持续读原始字节直到流结束；注意剥掉前导 `0x00` 字节再写文件）。
- 手册 Python/VISA 示例（p755）：设置 `chunk_size = 20*1024*1024`，`write("PRIN? BMP")`，`read_raw()`，字节写入文件。
- 相关：`:SAVE:IMAGe "<路径>",<BMP|JPG|PNG>,<OFF|ON>` 把截图保存到示波器存储（`local/...`、`U-disk0/...`、`net_storage/...`；invert=ON 反转为白底，适合打印）。
- 相关：`:SAVE:MATLab "<路径>",C1` 把通道波形数据以 .mat 保存到示波器存储。

### 4.6 波形数据读取（`WAV:DATA?`）

可通过 SCPI 读取原始波形采样点做程序化分析，无需截图（协议见编程手册 p663-678）：

```
WAV:SOUR C1           # 波形源（C1-C4，F1-F2 数学，D0-D15 数字）
WAV:WIDT WORD         # SDS2000X HD 必须设 WORD（12-bit ADC）；WORD=每点 16 位，高字节先传
WAV:STAR 0            # 起始点
WAV:INT 1             # 抽点间隔（抽取）
WAV:POIN 20000        # 传输点数
WAV:MAXP?             # 单次最大可传点数
WAV:PRE?              # WAVEDESC 描述块："#9<9位数字>" + 346 字节
WAV:DATA?             # 采样数据块："#N<N位数字>" + 数据 + 结尾 0x0A 0x0A
```

**SDS2000X HD 转换常数**（手册 p675 表 1）：`code_per_div = 480`，中心码 `2047`，满码 `4096`（12-bit）。

- WORD 模式重组：`data16 = byte[2i+1]*256 + byte[2i]`，再 `code = data16 >> 4`；`code > 2047` 时 `code -= 4096`（转有符号）。
- 电压换算：`V = code * (vdiv / code_per_div) - voffset`
  - `vdiv` = WAVEDESC 偏移 156 处 float（不含探头衰减的垂直档位）
  - `voffset` = 偏移 160 处 float；`code_per_div` = 偏移 164 处 float（本机应读出 480）
- 时间换算：`t = -delay - (timebase * 10/2) + index * interval`
  - `delay` = 偏移 180 处 double（触发偏移，秒）；`interval` = 偏移 176 处 float（采样间隔）
  - `timebase` = 偏移 324 处 short（枚举值，见手册 p672 表 2）
- 数据量大（100KB+），务必写文件，不要打印到控制台；必须用原始字节读取，不能用 ReadLine()。

### 4.7 内置信号发生器（WGEN）

示波器内置单通道函数发生器（前面板输出），语法同 Siglent SDG 系列。可脱离 ESP32 被测设备做自测（需 FG 选件授权——先查 `C1:OUTP?` 是否有响应，未授权机器会拒绝 WGEN 命令）：

```
C1:OUTP ON                    # 打开发生器输出（查询 → C1:OUTP ON,LOAD,HZ,PLRT,NOR）
C1:OUTP LOAD,50               # 负载：50（欧姆）| HZ（高阻）
C1:BSWV WVTP,PULSE            # 波形：SINE|SQUARE|RAMP|PULSE|NOISE|ARB|DC|PRBS|IQ
C1:BSWV FRQ,25000             # 频率 Hz（NOISE/DC 无效）
C1:BSWV DUTY,50               # 占空比 %（仅 SQUARE/PULSE）
C1:BSWV AMP,3                 # 幅度 Vpp
C1:BSWV OFST,1.5              # 偏置 V
C1:BSWV WIDTH,2E-5            # 正脉宽 s（仅 PULSE）
C1:BSWV SYM,50                # 锯齿波对称度 %（仅 RAMP）
C1:BSWV?                      # 查询全部参数
C1:SYNC ON                    # 同步输出
STL? BUILDIN                  # 列出内置任意波（索引,名称 对）
VOLTPRT ON                    # 过压保护
```

自测示例——产生 25kHz、3Vpp、50% 占空比 PULSE，环回 CH1 测量：

```
C1:BSWV WVTP,PULSE
C1:BSWV FRQ,25000
C1:BSWV DUTY,50
C1:BSWV AMP,3
C1:BSWV OFST,1.5
C1:OUTP ON
```

注意：幅度/偏置精度取决于负载设置（50 vs HZ）——用 10X 探头接示波器 1MΩ 输入时应设 `LOAD,HZ`。

### 4.10 串行协议解码（DECode）

支持两路解码总线（BUS1/BUS2），协议：IIC/SPI/UART/CAN/LIN（另 FLEXray/CANFd/IIS/M1553 为选件）。语法依据编程手册 pp.70–120。

```
DEC ON                      # 开启解码功能
DEC:BUS1 ON                 # 开启总线 1
DEC:BUS1:PROT UART          # 选择协议
DEC:BUS1:FORM HEX           # 显示格式 HEX|DEC|BIN|ASCII
DEC:BUS1:RES?               # 读取解码结果（首行为表头，帧间用 ';' 分隔）
```

**UART 解码配置：**
```
DEC:BUS1:UART:BAUD 115200bps    # 波特率，或 CUSTom,<300-20000000>
DEC:BUS1:UART:DLEN 8            # 数据位 5-9
DEC:BUS1:UART:PAR NONE          # 校验 NONE|ODD|EVEN
DEC:BUS1:UART:STOP 1            # 停止位 1|1.5|2
DEC:BUS1:UART:RXSOUR C1         # RX 源通道
DEC:BUS1:UART:TXSOUR C2         # TX 源通道
DEC:BUS1:UART:RXT 1.65          # RX 判决电平（V）
DEC:BUS1:UART:IDLE LOW          # 空闲电平 LOW|HIGH
DEC:BUS1:UART:BITO LSBF         # 位序 LSBF|MSBF
```

**I2C 解码配置：**
```
DEC:BUS1:IIC:SCLS C1 / SDAS C2  # SCL/SDA 源通道
DEC:BUS1:IIC:SCLT 1.65 / SDAT 1.65   # 判决电平
DEC:BUS1:IIC:RWBit ADDR         # R/W 位位置
```

**串行触发**（手册 pp.399+, 561+）：`:TRIGger:IIC`、`:TRIGger:SPI`、`:TRIGger:UART`、`:TRIGger:CAN`、`:TRIGger:LIN` 子系统，例如 `TRIG:IIC:COND ADDR` + `TRIG:IIC:ADDR <地址>` 可按 I2C 地址触发。可用于触发 ESP32 启动日志或 I2C 事务。

> 注意：本固件上 `DEC:BUS1:PROT?`、`RXSOUR?` 查询可能返回空，但设置命令有效；读解码数据用 `DEC:BUS1:RES?` 最可靠。

## 5. PWM 测量验证流程

### 5.1 理论占空比计算

实际 PWM 占空比由两级变换决定：

1. **功率校准**（`calibratePower`）：亮度% → 查表插值 → PWM%
2. **minDuty 偏移**（`setPwm`）：PWM% → 实际占空比

```
实际占空比 = (maxDuty - minDuty)/100 * 1023 * (calibratePower(brightness) / 100) / 1023 * 100 + minDuty
```

简化：`实际占空比 ≈ minDuty + (maxDuty - minDuty) * calibratePower(brightness) / 100`

### 5.2 验证步骤

1. 查询设备状态：`http://192.168.30.74/status?devicepwd=pengping&mode=get`
2. 读取 `whiteApplied`、`yellowApplied`、`fanSpeed`、`pumpSpeed`
3. 计算理论占空比
4. 用 SCPI 测量各通道 FREQ 和 DUTY
5. 对比实测值与理论值

### 5.3 灯开关控制

```
开灯：GET http://192.168.30.74/light?devicepwd=pengping&mode=set&onOffStatus=1
关灯：GET http://192.168.30.74/light?devicepwd=pengping&mode=set&onOffStatus=0
```

### 5.4 串扰判别实验

判断 C3/C4 信号是真实 PWM 还是 LED 串扰：

1. 开灯状态下测量 C3/C4，若有 25kHz 信号
2. 关灯后再次测量，若信号消失 → 串扰
3. 若信号仍在 → 真实 PWM 输出（需检查温控逻辑）

## 6. 完整测量工作流（25kHz PWM 配置 + 截图）

端到端流程：配置示波器测量 25kHz PWM 信号，读取测量值，截图存档。

```
# 0. 设置探头衰减（必须与物理探头匹配，标配为 10X）
:CHAN1:PROB VAL,1.00E+01
:CHAN2:PROB VAL,1.00E+01

# 1. 重置通道偏移（关键——残留偏移会把信号推出屏幕）
C1:OFST 0
C2:OFST 0

# 2. 设置垂直档位（1V/div 适配典型 1.4V 摆幅）
C1:VDIV 1
C2:VDIV 1

# 3. 设置时基（10us/div，40us 周期占约 4 格）
TDIV 1E-5

# 4. 配置触发（C1 上升沿，自动）
TRIG:EDGE:SOUR CHAN1
TRIG:EDGE:SLOP POS
TRIG:MODE AUTO
TRIG:EDGE:LEV 0.7        # ~0.7V 中点；VDIV=1V 时最大约 1.1V（钳位！）

# 5. 确认触发稳定
TRIG:STAT?               # → Trig'd 表示稳定触发

# 6. 启用并读取测量
C1:MEAS FREQ,ON
C1:MEAS DUTY,ON
C1:MEAS PKPK,ON
C1:MEAS PER,ON
C1:MEAS RMS,ON
C1:MEAS MAX,ON
C1:MEAS MIN,ON
C1:MEAS RISE,ON
C1:MEAS FALL,ON
C1:PAVA? FREQ            # → 2.50E+04 Hz
C1:PAVA? DUTY            # → 9.48E+01 %
C1:PAVA? PER             # → 4.00E-05 s
C1:PAVA? PKPK            # → 1.40E+00 V
C1:PAVA? RMS             # → 1.24E+00 V
C1:PAVA? MAX             # → 1.26E+00 V
C1:PAVA? MIN             # → -1.42E-01 V
C1:PAVA? RISE            # → 4.30E-09 s
C1:PAVA? FALL            # → 4.70E-09 s
```

> 最快方式：先发 `ASET` 自动设置，再微调 `VDIV`/`TDIV` 到目标值。
>
> **光标快速测频：**
> ```
> CURS ON
> CURS:MODE MAN,X
> CURS:X1 0
> CURS:X2 4.00E-05
> CURS:IXD?              # → 2.500E+04（25kHz）
> CURS OFF
> ```
