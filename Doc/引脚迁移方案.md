# 引脚迁移方案：ESP32-WROOM-32 → ESP32-S3

> 项目：ReadingLampController（阅读台灯控制器）
> 老硬件：ESP32-WROOM-32（NodeMCU-32S 兼容开发板，左右各 19 脚）
> 新硬件：ESP32-S3-DevKitC-1（左右各 22 脚）
> 制定日期：2026-11-08

---

## 1. 迁移原则

1. **物理位置优先**：老板位置 N 的信号 → 新板位置 N（最大限度减少硬件接线改动）
2. **冲突就近移位**：若新板同位置引脚不可用（PSRAM/Strapping/UART0），则选同列最近的可用引脚
3. **功能分组相邻**：编码器 CLK/DT、I²C SCL/SDA 等相关信号尽量物理相邻
4. **避开启动风险**：不将 Strapping 引脚用于上电时电平不确定的信号（如 I²C 数据线、开漏输出）

## 5. 风险评估与缓解

### 5.1 🟡 中风险项（需板端验证）

#### GPIO3 用作 LED_EN_A 输出
- **风险**：GPIO3 是 ESP32-S3 的 JTAG Strapping 引脚，上电时影响 ROM 日志输出和 JTAG 使能
- **缓解措施**：雾化器项目（Aotomizer4ESP32S3）已使用 GPIO3 作 I2C SCL（输出）并稳定运行数百小时，证明可作普通 GPIO 输出。LED_EN 为上电后驱动的推挽输出，不影响启动时序
- **验证方法**：上电时观察 LED 是否误亮；示波器测量 GPIO3 上电电平

#### GPIO40 (MTDO) 用作编码器 CLK 输入（IRQ）
- **风险**：GPIO40 = MTDO（JTAG 数据输出），作 GPIO 时 JTAG 调试功能不可用
- **缓解措施**：生产环境不使用 JTAG，无影响。ESP32-S3 所有 GPIO 均支持外部中断
- **验证方法**：板端旋转编码器，确认 IRQ 回调正常触发

#### GPIO39 (MTCK) 用作编码器 DT 输入（IRQ）
- **风险**：GPIO39 = MTCK（JTAG 时钟），同上
- **缓解措施**：同上
- **验证方法**：同上

### 5.2 🟢 低风险项

| 引脚 | 用途 | 说明 |
|------|------|------|
| GPIO16/17 | PWM (white/yellow) | XTAL_32K_P/N，不使用外部 32K 晶振时可作普通 GPIO。雾化器项目已验证 |
| GPIO18 | PWM (pump) | 普通 GPIO，LEDC PWM 无限制 |
| GPIO7 | SoftI2C SCL | 普通 GPIO |
| GPIO42 | SoftI2C SDA | MTMS，I²C 开漏输出有上拉，上电为高电平，不影响 Strapping |
| GPIO1 | 编码器 KEY | 普通 GPIO，输入带内部上拉 |
| GPIO2 | HardI2C SCL (死) | 非 Strapping，死代码不运行 |
| GPIO41 | HardI2C SDA (死) | MTDI Strapping，但死代码不初始化，无影响 |
| GPIO48 | WS2812 | 雾化器项目已验证 |

### 5.3 S3 Strapping 引脚使用状态

| S3 GPIO | Strapping 功能 | 本项目使用 | 状态 |
|---------|---------------|-----------|------|
| GPIO0 | 下载模式 | 否 | ✅ 安全 |
| GPIO3 | JTAG/ROM日志 | LED_EN_A 输出 | ⚠️ 已验证可用 |
| GPIO45 | VDD_SPI 电压 | 否 | ✅ 安全 |
| GPIO46 | ROM 日志 | 否 | ✅ 安全 |

> 注：GPIO41（MTDI）、GPIO40（MTDO）、GPIO39（MTCK）、GPIO42（MTMS）为 JTAG 引脚，**非 Strapping 引脚**。作 GPIO 使用时仅丧失 JTAG 调试能力，不影响启动。本项目中 GPIO39/40/42 用于编码器与 I²C，GPIO41 为死代码 HardI2C，均不影响启动。

  右4  GPIO1   编码器 KEY ─┐

## 8. 后续更改指南

如需调整引脚分配，按以下顺序检查：

1. **Strapping 引脚**（GPIO0/3/45/46）：避免用于上电时电平不确定的信号
2. **JTAG 引脚**（GPIO39/40/41/42）：非 Strapping，但作 GPIO 时丧失 JTAG 调试，生产环境无影响
3. **Octal-PSRAM 引脚**（GPIO32-37）：Octal-SPIRAM 固件下不可用
4. **UART0 引脚**（GPIO43/44）：REPL 调试串口，不可占用
5. **USB-OTG 引脚**（GPIO19/20）：启用 USB 时不可用，本项目不用 USB-OTG，可用
6. **板载 RGB LED**（GPIO38）：部分 S3-DevKitC-1 版本有板载 WS2812 在此脚，使用时注意

调整后请更新本文件第 3 节映射表和第 5 节风险评估。
